Process

Nothing gets designed before it gets understood.

  1. 01

    Sit in the workflow

    Interviews with the people doing the job daily — agents, coordinators, the person answering the phone. The friction is always specific.

  2. 02

    Map before pixels

    Flows, states, and edge cases first. Wireframes in Figma get argued over while they are still cheap to change.

  3. 03

    Design the system

    Type, color, spacing, and components defined once, so page five costs a fraction of page one and everything stays consistent.

  4. 04

    Build and hand over

    Hand-written HTML, CSS, and JavaScript. Documented, deployed, and explained in plain language so you are never locked in.

Good software for a small business is not a smaller version of enterprise software. It is software that knows what the day looks like.

The studio

One person, on purpose.

I am Sou Her, a creative technologist based in Gainesville, Georgia. NomSou Services grew out of NOMSOUcodes — a habit of building the tool rather than complaining about the one that exists.

My focus is real estate: brokerages, property managers, and the local businesses that orbit them. That means I already know what an MLS feed does on a bad day, why agents keep listings in a spreadsheet, and how much of a transaction still runs on text messages. I also build AI back-office tools, so when a workflow is better automated than redesigned, I can say so honestly.

You work with me directly, from the first conversation through launch. Nothing is outsourced, nothing is dropped onto a template, and the code you end up with is code a person can read.

  • Design — Figma, brand systems, UI/UX, accessibility to WCAG 2.1 AA
  • Build — Hand-written HTML/CSS/JS, React, Supabase, Netlify
  • Automate — AI agent workflows for intake, follow-up, and back-office admin
